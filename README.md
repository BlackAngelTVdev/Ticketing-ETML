# Système de ticketing - Section INF

## Fonctionnalités générales
- Connexion via Eduvaud (groupe de l'ETML)
- Séparer les tickets par des catégories (problèmes / demandes / projets / général / idées)
- Utilisation de GLPI comme système de ticketing
- Attribution des tâches
- Statut de la tâche
- Système de rôles / droits
- Uniquement pour le site de Vennes (pour la section INF uniquement)
- Urgence de la tâche → définie par l'équipe
- Versioning
- Ajout de pièces jointes sur le ticket (Gérer la sécurité)
- Date de fin

## Acteurs et droits

| Acteur         | Droits |
|----------------|--------|
| Client         | CRUD ticket |
| Administrateur | CRUD ticket · S'attribuer une tâche |
| Superadmin     | Gérer le système de ticketing · Attribution de tâche à tous |

## Contenu d'un ticket
- Titre
- Description
- Ajout de fichiers
- Date de fin
- Catégorie
